# Level Up HQ

Private operations dashboard for Level Up Cornhole. The site holds no data: after you sign in with Google it reads the Level Up HQ sheet with your own read-only access. Accounts without access to the sheet see nothing.

- Setup: see SETUP.md (one-time Google sign-in key).
- Sample preview with made-up data: add `?demo=1` to the URL.
- Design notes: DESIGN-NOTES.md.
